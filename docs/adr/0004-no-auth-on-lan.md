# HTTP 端点不做鉴权，只在局域网监听

服务端把 Mac 的实时状态暴露在 `0.0.0.0:8737`，任何能连上这台机器的人都能读到。我们不做鉴权。

理由：这是家庭局域网，数据是「CPU 占用率」这种看一眼屏幕就能看到的量，没有机密性可言。加鉴权意味着客户端多一个配置项、服务端多一段校验代码、以及「token 忘了填导致副屏一片 `--`」这种纯自找的故障模式。

服务端绑 `0.0.0.0` 而不是 `127.0.0.1`，因为 iPhone 必须能从局域网连进来。

## 什么时候该推翻

这台 Mac 接入不受信任的网络（咖啡厅、共享办公、访客 VLAN）时。届时最省事的做法是在 URL 里加一个静态 token（`GET /api/stats?t=...`），而不是引入完整的认证方案。
